# SOVANN FARM — Premium Cambodian Agriculture E-Commerce

## Project Brief
Premium, editorial-style e-commerce experience for Cambodian agriculture ("SOVANN FARM — From Cambodian Soil, To Your Table").
Design language: Apple minimalism + Bellroy storytelling + Logines editorial elegance + Frans Hals cultural authenticity + Gucci luxury campaign energy — combined into an original Cambodian agricultural brand identity.

## Technical Reality (sandbox constraints)
- Stack: Next.js 16 App Router + TypeScript + Tailwind CSS 4 + shadcn/ui + zustand + TanStack Query + Prisma/SQLite. Angular/Bootstrap are NOT available in this sandbox; the full feature set is implemented with the available stack.
- IMPORTANT: Only ONE user-visible route `/` (preview panel limitation). All "pages" (home, shop, product, farmers, stories, about, cart, checkout, confirmation, wishlist, account) are client-side views switched via a zustand view-router with URL hash sync (#/shop, #/product/kampot-black-pepper...).
- API routes under /api/* (products, farmers, stories, provinces, newsletter, orders) — mock data served from src/lib/data/*, orders/newsletter persisted to SQLite via Prisma.
- Dev server: `bun run dev` port 3000 (already running, logs in /home/z/my-project/dev.log). NEVER `bun run build`.
